# Balance report

Generated by `npm run balance` (`scripts/balance.mjs`): Hard bot vs Hard bot, every ordered class pair, no mutators.

- **Rounds:** 8400 (200 per ordered pair, 7 classes, 42 ordered pairs)
- **Maps:** Open Court, Four Chambers, Bastions (round *r* of a pair plays map *r* mod 3)
- **Seed:** 1
- **Wall time:** 87.4s on 4 parallel headless browsers, fixed 60 Hz steps, no rendering
- **Draws:** 0 mutual kills, 0 timeouts (round still running after 180s game time)
- **Average round length:** 5.0s game time

Win rate = wins / decided rounds; draws and timeouts count for neither side.

## Before and after the W-7 balance pass

Same harness, seed and rounds. *Before* is this report as committed by holiday W-6 (class numbers before W-7); target band 42 to 58 percent overall. This section is written by hand, so a fresh `npm run balance` drops it; git history keeps it.

Changes (`src/systems/Classes.js`):

- Arcanist: normal-shot cooldown multiplier 0.72 → 0.93
- Pyromancer: Flame Burst cooldown 10s → 8s, spark damage 8 → 14
- Cryomancer: Frost Ring cooldown 10s → 6s, slowed foes move at 45% speed for 2.5s → 60% speed for 3.5s (a milder slow that lasts longer)
- Stonecaller: Breach cooldown 12s → 9s; passive adds a 0.9 normal-shot cooldown multiplier (Breach alone did not move its win rate: with Breach switched off it stayed at 31%, so it needed a stat)
- Stormcaller: Zap Dash cooldown 9s → 11s, stun 0.9s → 0.65s
- Warden: Reflect Ward cooldown 10s → 12s
- Trickster: Scatter Dash cooldown 9s → 7s, backward pellet damage 12 → 15
